Drippy.JS Befehlsliste

Alle verfügbaren Slash-Commands für deinen Discord-Server

🛡️ Moderation

/ban
Sperrt ein Mitglied dauerhaft vom Discord-Server.
/kick
Wirft ein Mitglied vom aktuellen Discord-Server.
/timeout
Versetzt ein Mitglied für eine bestimmte Zeit in den Timeout (Stummschaltung).
/warn
Erteilt einem Nutzer eine Verwarnung und loggt diese im System.
/clear
Löscht eine festgelegte Anzahl von Nachrichten in einem Textkanal.
/lockdown
Sperrt den aktuellen Kanal schnell ab, um Nachrichten-Spam zu verhindern.
/slowmode
Aktiviert oder ändert die Nachrichten-Abklingzeit eines Kanals.

⚙️ Administration & Setup

/config-view
Zeigt die aktuell konfigurierten Bot-Einstellungen des Servers an.
/set-lang
Ändert die Standardsprache von Drippy auf diesem Server.
/setup-verify
Richtet ein Verifizierungssystem (z.B. per Button) für neue Mitglieder ein.
/setup-welcome-message
Richtet die automatische Begrüßungsnachricht für neue User ein.
/remove-welcome-channel
Entfernt den konfigurierten Willkommenskanal des Bots.
/ticket-setup
Konfiguriert das Ticket-Support-System mit Buttons oder Dropdowns.
/feedback-setup
Richtet einen Kanal für das Sammeln von Server-Feedback ein.
/appeal-reply
Antwortet offiziell auf den Entbannungsantrag (Appeal) eines Nutzers.
/setappealchannel
Legt den Kanal fest, in dem eingehende Entbannungsanträge gelistet werden.
/faq-admin
Ermöglicht Administratoren das Hinzufügen oder Bearbeiten von FAQ-Einträgen.

ℹ️ Utility & Info

/info
Zeigt technische Details, Uptime, Entwickler und Statistiken von Drippy an.
/help
Zeigt eine kompakte Hilfe-Übersicht und den Link zu dieser Dokumentation.
/serverinfo
Liefert umfassende Statistiken und Details über den aktuellen Server.
/userinfo
Zeigt Informationen über ein bestimmtes Mitglied (Rollen, Beitrittsdatum etc.).
/rules
Gibt das Regelwerk des Servers aus (sofern eingerichtet).
/faq
Ruft die vom Server-Team vordefinierten häufig gestellten Fragen ab.
/appeal
Ermöglicht es Nutzern, ein Formular für einen Entbannungsantrag aufzurufen.
/suggest
Reicht einen neuen Verbesserungsvorschlag für den Server ein.

🎮 Fun, Leveling & System

/level
Zeigt dein aktuelles Level und deine XP-Fortschrittsleiste auf dem Server an.
/leaderboard
Zeigt die Rangliste der aktivsten Mitglieder (XP/Level) an.
/birthday
Trage deinen Geburtstag ein oder schaue nach, wer heute feiert.
/boost
Zeigt Infos zu Server-Boostern oder speziellen Belohnungen an.
/lfg
Looking For Group: Starte eine Suche nach Mitspielern für Gaming-Sessions.
/guessthenumber
Ein kleines Minispiel: Errate die vom Bot generierte Zufallszahl.
/quiz
Spiele ein interaktives Quiz und teste dein Wissen.
/meme
Postet ein zufälliges, lustiges Meme aus dem Internet.
/rating
Lässt den Bot etwas auf einer Skala bewerten oder bewertet ein Mitglied.
/ping
Prüft die aktuelle Latenz (Verbindungsgeschwindigkeit) zum Discord-Server.
/bug
Ermöglicht Nutzern, Fehler des Bots direkt an die Entwickler zu melden.
