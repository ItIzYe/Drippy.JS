Drippy.JS Befehlsliste

Alle verfügbaren Slash-Commands mit korrekten Anwendungsbeispielen

🛡️ Moderation

/ban
Sperrt ein Mitglied dauerhaft vom Discord-Server.
Usage: /ban [user] [reason]
/kick
Wirft ein Mitglied vom aktuellen Discord-Server.
Usage: /kick [user] [reason]
/timeout
Versetzt ein Mitglied in den Timeout (Stummschaltung).
Usage: /timeout [user] [duration] [reason]
/warn
Erteilt einem Nutzer eine Verwarnung und loggt diese.
Usage: /warn [user] [reason]
/clear
Löscht eine festgelegte Anzahl von Nachrichten in einem Kanal.
Usage: /clear [amount]
/lockdown
Sperrt oder entsperrt den aktuellen Textkanal für normale User.
Usage: /lockdown [true/false]
/slowmode
Aktiviert oder ändert die Nachrichten-Abklingzeit eines Kanals.
Usage: /slowmode [seconds]

⚙️ Administration & Setup

/config-view
Zeigt die aktuell konfigurierten Bot-Einstellungen des Servers an.
Usage: /config-view
/set-lang
Ändert die Standardsprache von Drippy auf diesem Server.
Usage: /set-lang [de/en]
/setup-verify
Richtet ein Verifizierungssystem per Button ein.
Usage: /setup-verify [channel] [role]
/setup-welcome-message
Richtet die automatische Begrüßungsnachricht für neue User ein.
Usage: /setup-welcome-message [channel]
/remove-welcome-channel
Entfernt den konfigurierten Willkommenskanal des Bots.
Usage: /remove-welcome-channel
/ticket-setup
Konfiguriert das Ticket-Support-System mit einem Button-Embed.
Usage: /ticket-setup [channel] [category]
/appeal-reply
Antwortet offiziell auf den Entbannungsantrag (Appeal) eines Nutzers.
Usage: /appeal-reply [user_id] [status] [reason]
/setappealchannel
Legt den Kanal fest, in dem Entbannungsanträge eingehen.
Usage: /setappealchannel [channel]
/faq-admin
Ermöglicht das Hinzufügen, Löschen oder Bearbeiten von FAQ-Einträgen.
Usage: /faq-admin [action] [question] [answer]
/rules add
Fügt eine Regel hinzu.
Usage: /rules add [subpoint] [add after]
/rules remove
Entfernt eine Regel.
Usage: /rules remove [rule]
/rules list
Gibt das Regelwerk aus.
Usage: /rules list
/embed-preview
Erstelle und sende ein Embed.
Usage: /embed-preview
/sticky
Erstelle Sticky Notes.
Usage: /sticky [text] [intervall (messages)]

ℹ️ Utility & Info

/info
Zeigt technische Details, Uptime, Entwickler und Statistiken an.
Usage: /info
/help
Zeigt eine kompakte Hilfe-Übersicht und den Link zum Wiki.
Usage: /help
/serverinfo
Liefert umfassende Statistiken und Details über den aktuellen Server.
Usage: /serverinfo
/userinfo
Zeigt Informationen über ein bestimmtes Mitglied (Rollen, Beitritt).
Usage: /userinfo [user]
/faq
Ruft die vom Server-Team erstellten FAQs ab.
Usage: /faq [topic_id]
/appeal
Öffnet das interaktive Formular für einen Entbannungsantrag.
Usage: /appeal
/suggest
Reicht einen neuen Verbesserungsvorschlag für den Server ein.
Usage: /suggest [suggestion]
/timestamp
Konvertiere eine Zeit zu einem Timestamp.
Usage: /timestamp [HH:MM] [optional: DD.MM.YYYY]

🎮 Fun & Leveling

/level
Zeigt dein aktuelles Level und deine XP-Fortschrittsleiste an.
Usage: /level [user]
/leaderboard
Zeigt die Rangliste der aktivsten Mitglieder (XP/Level) an.
Usage: /leaderboard
/birthday
Trage deinen Geburtstag ein oder lasse dir die heutigen Geburtstage anzeigen.
Usage: /birthday [set/view] [date]
/boost
Zeigt Infos zu Server-Boostern oder speziellen Boost-Vorteilen.
Usage: /boost
/lfg
Looking For Group: Starte eine Suche nach Mitspielern für Games.
Usage: /lfg [game] [players_needed]
/guessthenumber
Ein kleines Minispiel: Errate die vom Bot generierte Zufallszahl.
Usage: /guessthenumber [your_guess]
/quiz
Spiele ein interaktives Quiz und teste dein Wissen im Chat.
Usage: /quiz [category]
/meme
Postet ein zufälliges, lustiges Meme aus dem Internet.
Usage: /meme
/ping
Prüft die aktuelle Latenz zum Discord-Server.
Usage: /ping
/bug
Ermöglicht Nutzern, Fehler des Bots direkt an die Entwickler zu melden.
Usage: /bug [description]
